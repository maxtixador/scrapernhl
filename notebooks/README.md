# ScraperNHL Tutorial Notebooks

This directory contains interactive Jupyter notebooks to help you learn how to use ScraperNHL.

## New Structure Tutorials (v3.0+)

These notebooks demonstrate the new unified API structure:

1. **01_getting_started.ipynb** - Basic usage and core concepts
2. **02_nhl_data.ipynb** - Working with NHL data
3. **03_other_leagues.ipynb** - QMJHL, OHL, WHL, and AHL scrapers
4. **04_advanced_features.ipynb** - Caching, rate limiting, and transformations

## Archive

The `archive/` folder contains notebooks from previous versions for reference:
- Old multi-league examples (v0.1.5)
- Legacy API demonstrations
- Historical testing notebooks

## Running the Notebooks

```bash
# Install Jupyter if needed
pip install jupyter

# Start Jupyter
jupyter notebook

# Or use JupyterLab
jupyter lab
```

## Quick Start

Open `01_getting_started.ipynb` to begin learning ScraperNHL!
